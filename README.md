# Homebrew tap for the Tempr CLI

```sh
brew tap chrissalomon/tempr
brew trust chrissalomon/tempr
brew install tempr
```

Homebrew asks you to trust a tap before it installs from it; `brew trust` does that once.

Updates with `brew upgrade tempr`. The formula installs the same archives as the
[install script](https://temprhq.io/cli); see [temprhq.io/cli](https://temprhq.io/cli) for what the
CLI does and [the docs](https://temprhq.io/docs/quickstart-cli) to get started.
